# Hi, I’m Alvira Rahman

I’m pursuing entry-level IT help desk and technical support roles, with a long-term goal of becoming a cloud engineer.

I build hands-on labs to practice Windows administration, networking, troubleshooting, and AWS. I document what I configured, the problems I investigated, and how I verified the results.

## Featured projects

- [Active Directory Home Lab](https://github.com/Alvira-Rahman/active-directory-home-lab) — Built a Windows domain, resolved a DNS/IP configuration problem, joined a Windows 11 client, and verified domain-user sign-ins.

- [AWS IAM Security Lab](https://github.com/Alvira-Rahman/aws-iam-security-lab) — Practice with users, groups, roles, and permission testing.

- [AWS Static Website Deployment](https://github.com/Alvira-Rahman/spacex-clone-aws) — S3 and CloudFront deployment with documented troubleshooting.

Windows support • Active Directory • DNS • Networking • Ticketing workflows • AWS
